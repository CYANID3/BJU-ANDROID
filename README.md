# БЖУ - Android / Capacitor

## Что изменено
- Capacitor оборачивает существующий HTML-интерфейс в Android-приложение.
- `@capacitor/filesystem` сохраняет данные в `Documents/BJU/bju-data.json`, а резервную копию - в `Documents/BJU/bju-backup.json`.
- Данные автоматически сохраняются после изменений и загружаются при запуске.
- `@capacitor/haptics` используется для нативной тактильной отдачи; в браузере остаётся `navigator.vibrate`.
- GitHub Actions собирает debug APK при каждом push в `main` и вручную через вкладку Actions.

## Сборка через GitHub
1. Распакуйте проект и загрузите содержимое в репозиторий `CYANID3/BJU-APP` (с заменой существующих файлов).
2. Убедитесь, что в репозитории включён GitHub Actions.
3. Сделайте commit/push в `main` либо запустите workflow вручную: **Actions -> Build Android APK -> Run workflow**.
4. Откройте завершившийся запуск и скачайте артефакт `BJU-APP-debug-apk`.
5. Распакуйте артефакт и установите `app-debug.apk` на Android.

## Важные замечания
- APK будет debug-сборкой для личной установки, не подписанной релизным ключом Google Play.
- При первом запуске проверьте, что приложение создаёт файл в `Documents/BJU/`. Android и конкретные версии Capacitor могут по-разному ограничивать доступ к общедоступным каталогам. Если сохранение в публичный Documents блокируется на целевом Android, потребуется использовать системный выбор места сохранения (Storage Access Framework) или каталог приложения.
- Данные приложения также остаются в `localStorage`. Не удаляйте данные приложения, пока не проверите файл резервной копии.
- Workflow генерирует папку `android` во время сборки, поэтому она намеренно не хранится в исходниках.
